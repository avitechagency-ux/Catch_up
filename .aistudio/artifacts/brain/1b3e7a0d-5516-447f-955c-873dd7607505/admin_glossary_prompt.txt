Please build a Glossary Management Page for the Admin Panel. This page will manage the content displayed in the mobile app's Glossary section.

1. Database Requirement
The app currently fetches glossary terms directly from a Supabase table named glossary_terms. Ensure this table exists with the following schema:
- id (UUID, primary key)
- term (Text, required)
- subject (Text, required)
- target_class (Text, required, e.g., 'S.1', 'S.4', 'S.1-S.6')
- definition (Text, required)
- example_usage (Text, nullable)
- is_approved (Boolean, default: true)

2. Required Admin Features
- Data Table: Display all terms in a paginated or searchable table.
- Search & Filter: Implement search by 'term' or 'definition' and a subject-based filter dropdown (All, Mathematics, Physics, etc.) to mirror the app’s filtering logic.
- Form Management: Create a clean form/modal for Adding and Editing terms with fields corresponding to the database schema above (ensure subject and target class are standardized inputs/dropdowns).
- CRUD Operations: Allow admins to Add new terms, Edit existing definitions, and Delete obsolete terms.

3. Data Synchronization
The mobile app directly queries this glossary_terms table. Any changes made through this admin panel must update the table immediately so they are reflected in the app upon the next refresh. Ensure the UI is clean, intuitive, and matches our existing admin design principles.
